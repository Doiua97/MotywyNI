Zakres docelowy obejmuje cały interfejs, jak w Dwarven. Nie przenosimy żadnych grafik Dwarven ani jego geometrii. Nowa oprawa ma zachować natywne pozycje, rozmiary i skalowanie klienta. Oryginalne ikony widgetów, przedmiotów i umiejętności klienta pozostają zgodnie z ustaleniami.

Motyw nie zawiera pełnego CSS klienta. Brak testu zalogowanej gry i pomiaru płynności.
