# MotywyNI

Autorskie motywy nowego interfejsu Margonem. Każdy motyw ma własny katalog, grafiki, arkusz CSS i osobny mały userscript Tampermonkey.

| Motyw | Wersja | Instalacja |
| --- | --- | --- |
| [Polarna Pracownia](Polarna-Pracownia/README.txt) | 1.0.0 — do całościowego testu w grze | [Userscript](https://raw.githubusercontent.com/Doiua97/MotywyNI/main/Polarna-Pracownia/install/polarna-pracownia.user.js) |

Po otwarciu odnośnika userscriptu zainstaluj go w Tampermonkey. Wyłącz poprzedni motyw i przeładuj grę. Instalator ładuje wyłącznie CSS motywu i jego zasoby z przypiętego wydania; nie dołącza pełnego CSS klienta.

Kontrole lokalne i ich ograniczenia są opisane w dokumentacji motywu. Brak testu zalogowanej gry oraz potwierdzenia płynności przez użytkownika.
